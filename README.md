## 🚀 Getting Started

To run these programs on your local machine:

**1. Clone the repository**

```bash
git clone https://github.com/varuna-code7/cpp-basics.git
```

**2. Navigate to the project directory**

```bash
cd cpp-basics
```

**3. Compile a C++ program**

For example:

```bash
g++ array.cpp -o array
```

**4. Run the program**

On Windows:

```bash
.\array.exe
```
